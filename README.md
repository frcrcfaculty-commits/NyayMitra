# NyayMitra

NyayMitra is an open-source Legal Firm Application built for Indian Citizens to understand their rights and interact with Legal AI.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase (PostgreSQL, Edge Functions)

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Run development server:
   ```bash
   pnpm run dev
   ```
